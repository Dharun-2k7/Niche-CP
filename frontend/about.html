Platform Infrastructure

About NicheCP

NicheCP is a production-grade competitive programming platform developed and maintained by the Amrita Nagercoil ICPC Club.

Mission & Purpose

Engineered to host campus-wide algorithmic contests, manage problem archives, execute untrusted user submissions safely in isolated Docker containers, and deliver real-time leaderboard analytics with millisecond precision.

System Architecture

1

Nginx & Frontend Client

Static HTML5/ES6 client served behind Nginx reverse proxy with SSL termination and dynamic API routing.

2

Go (Gin) API Server

High-concurrency Go API handling authentication, RBAC, profile image uploads, and enqueuing jobs to Redis queues without host Docker socket exposure.

3

Redis & PostgreSQL Persistence

PostgreSQL 15 for users, problems, submissions, and contest state; Redis 7 for rate-limiting, OAuth tokens, and background worker queues.

4

Docker Execution Worker

Isolated Go Worker consuming Redis queues and running code sandboxes inside Alpine containers under strict memory, CPU, and PID cgroup constraints.
