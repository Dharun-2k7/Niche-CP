NCP-003 Graph BFS Traversal Medium
Starter Round 5 • Problem 2
Statement

Given an undirected graph with N nodes and M edges, and a source node S, print the BFS traversal order starting from S.

Nodes are numbered from 1 to N. If there are multiple valid traversal orders, print the lexicographically smallest one.

Input Format
First line: N M S
Next M lines: u v (edge between u and v)
Output Format
Print space-separated node indices in BFS order.
